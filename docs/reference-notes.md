# オイルタイマー観察メモ

参考写真(ユーザー提供 3 枚)とWeb調べから、再現のために押さえる点。

## 構造
- 外形: 断面が四角いアクリルの柱。側面はゆるくくびれる。上下に厚い透明ブロック(高さの約1割ずつ)。
- 上の部屋: 底が浅いV字の仕切り。V の頂点(中央)に細いノズルがあり、そこから滴が落ちる。
  壁際にもすき間があり、そこから落ちる列ができることもある。
- 下の部屋: 上面が山型(^)の仕切り。落ちた滴は斜面を滑り、端のすき間から下の部屋へ入る。
- 上下が同じ形なので、ひっくり返すとまた落ち始める。

## 液体
- 基本原理(自作オイルタイマーの図解より): 2つの部屋はそれぞれ液体で満タン。重い液は「低い穴」から落ち、
  軽い液は「高い穴(管)」から昇る。通り道が別々なので詰まらずに入れ替わり続ける。
- 透明な液体の中を、色付きの液体(油と水の組み合わせ)が滴になって沈む。
- 密度差で沈む/浮くが決まり、粘り気で落ちる速さが決まる。
- 2色は混ざらない。写真1では2色とも透明な液体より重く、上の部屋の真ん中のノズルから、交互に落ちる
  (ノズル直下の最初の滴はピンク、そのあと青・ピンクが交互)。上の部屋では V字の上にピンクが薄く、その上に青。
  左右の壁際からは漏れない(ユーザー確認)。
- (片方が昇るタイプもありそうだが、写真1はそうではない)
- 滴は丸く少し平たい。数珠のように1列で、ほぼ一定の速さで落ちる。色ごとに速さが少し違う。
- 2色の滴は奥行きが違うので重なり、重なった部分は濃い色になる(青×ピンク→濃紺)。

## 見た目
- 滴はほぼ均一な半透明の色。縁に細く濃い線、片側に小さなツヤ。立体感は控えめ。
- 色の組み合わせ例: 青×ピンク、水色×薄紫、緑×青、赤×黄。
- 上下の透明ブロックに中の液体の色が映り込む。

## 調べられなかったこと
- 流体の正確な密度・粘度、ノズルの寸法は公開情報が見つからなかった。
- 解説資料の一部(flowvis.org など)はこの環境のネットワーク制限で読めなかった。

## 動画(4本並んだタイマー)からの追加の観察
- 2色とも上の部屋から落ちる。上の部屋では重い色がV字の底に薄く、その上に軽い色。
- ノズルの先に涙形の滴がぶら下がり、表面張力で耐えてから切れて落ちる。
- 左右の壁ぎわに見える滴の列は、壁に映った反射(ユーザー確認)。
- 下の仕切り(山型)に落ちた滴は溶け合わず、粒のまま積み重なり、端から下の部屋へ流れる。

## アプリでの採用(ユーザーの希望)
- 2色とも上から落ちる(動画どおり)。
- 仕切りは V字/山型の両端が「スカート」として容器の端の方へ伸び、スカートと壁の間が通り道になる
  (上下とも開いている。ユーザーの図解より)。
  - 上の部屋: 液はスカートの内側(コップの中)にたまり、ふつうは真ん中のノズルから出る。
  - 下の部屋: 山型に落ちた滴は両端へ滑り、スカートと壁の間を伝って底へ入る。
- 上側のノズルでは、涙形にぶら下がってから切れて落ちる。
- たまる部屋は小さくして、滴が落ちる様子を主役にする。

## 容器の厚み(ユーザー指摘・横からの写真)
- 厚いのは上下のコップの内側と容器の端のあたりだけ。コップの外側(お皿のすぐ外から、壁との細いすき間も)はすべて
  とても薄い板状のすき間(ユーザー確認)。
  滴は前後の壁に押さえられて平たく広がり、正面からは大きな丸に見える(ヘレ・ショウ・セル)。
  ふちがくっきり、ツヤは控えめ。壁との抵抗が大きくゆっくり落ちる。上下の部屋の液は立体的。

## 色のテーマ: 春夏秋冬
- 春: 桜色と菜の花 / 夏: 海とひまわり / 秋: もみじと銀杏 / 冬: 雪と氷

## 写真との見比べで合わせたこと
- 真ん中の滴: 大きさがばらばら、少し横長の楕円、列は左右にゆらいでジグザグ、間隔は詰まり気味。
- 色: 厚い部屋は深く濃い色、薄い真ん中は明るめ。重なりは掛け合わせ(青×ピンク → 濃紺)。
- 上の部屋は容器の端の近くまで満ち、重い青が下の層。部屋の中の液は平らに広がる。
- 仕切りは透明なアクリルなので、ほとんど見えない。側面のアクリルに液の色がうっすら映る。

## 上下の部屋の立体感(3本並んだ写真より)
- 少し上から見ているので、受け皿にたまった液は「手前の面」と「明るい平らな上面」が見える。上面の奥の縁に細い濃い線。
- 受け皿の中で2色が左右に並んで見えるのは、表と裏の2層に分かれた液を斜めから見ているためと考えられる。
- 仕切りは奥行き方向に伸びた斜めの透明な板として見える。下の部屋は床の面と液の上面が見える。
- 下の部屋の、丸い粒が密集した様子は再現しない(ユーザー指定)。

## 決まりごと(ユーザー確認済み)
- 青とピンクは表と裏の2層に分かれていて、部屋の中も真ん中も、別の色とは一切ぶつからない。
- 写真の読み取りで迷ったら、作る前にユーザーに確認する。
- 「真ん中しか通れない」というルールは無い。どの穴・すき間も開いていて、通りやすさは形と重さで決まる(ユーザー確認):
  - ＼／(上のV字の真ん中の穴): 液が集まるので通りやすい
  - ／＼(下の山型の頂点の穴): 液が離れていくので通りにくい
  - ／ |(上の仕切りの端と壁のすき間): 液がたまる所から遠く高いので通りにくい
  - ＼ |(下の仕切りの端と壁のすき間): 坂を滑り下りた先なので通りやすい
- 上の部屋がたっぷり入っていても横のすき間から溢れないのは、界面張力のため(ユーザー確認)。
  2つの液の重さの差が小さいので、細いすき間に入りこもうとする力より、境目の膜の力が勝つ。
  強く振ったり大きく傾けたりして押す力が勝ったときは、すき間から流れ出てよい。
- 真ん中のノズルの「見えない開け閉めする板」は残す(ユーザー確認)。
- 上下の部屋の上面は、手前の面と線で区切らず、つなぎ目なくなじませる(二重に見えないように)。

## 仕切りの形(複数の写真から、ユーザー確認済み)
- 上下同じ部品をひっくり返した形。コップは容器とほぼ同じ幅で、壁とのすき間はとても細い(滴よりずっと細い)。
- 底は壁ぎわから真ん中の穴まで丸くなめらか(お皿)。下側は、ふせたお皿の丸い山になる。
- コップの縁は容器の端のすぐ近くまで伸び、縁と端の間に少しだけすき間(液が減ったぶん透明な液が入る道)。
- 始めはコップの縁のすぐ下までたっぷり。縁の外にははみ出さない。
- 下の部屋: 滴は山の斜面を滑って左右の端へ → 細いすき間を下る → 底のすき間から容器のいちばん下へ。
  底いっぱいに広がり、ふせたお皿の内側へもたまる。
- 赤い線(コップの壁)より外の色は、漏れた液。再現しない。
- すき間の入口は滴よりずっと細いので、入口の上に来た小さな滴は乗らずにコップの中へ転がり落ちる。
